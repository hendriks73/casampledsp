# casampledsp-x86_64

Canonical C++ source module for macOS x86_64. **All C++ sources live here.** The `casampledsp-aarch64` module points its compiler at `../casampledsp-x86_64/src/main/c/` — there is only one copy of the native code.

## Build

```bash
mvn install -pl casampledsp-java,casampledsp-x86_64

# Enable C-level debug output to stdout:
mvn install -pl casampledsp-java,casampledsp-x86_64 -Dcflags=-DDEBUG
```

Requires Apple Command Line Tools or Xcode.

## C++ Sources (`src/main/c/`)

| File | Role |
|---|---|
| `CAUtils.cpp` / `CAUtils.h` | Shared helpers: JNI exception mapping, `ca_jstring_to_utf8()` (UTF-8 string extraction for emoji-safe path handling), `ca_create_url_ref()` (Java string → `CFURLRef`), and the `CAAudioIO`/`CAAudioConverterIO`/`CAAudioFileIO`/`CAAudioStreamIO` struct definitions. |
| `CAAudioFileReader.cpp` | Implements `getAudioFileFormatsFromURL`. Opens file via `AudioFileID`, reads properties (format, sample rate, duration, byte length). |
| `CAURLInputStream.cpp` | Opens audio file by URL; reads compressed packets via `AudioFileID` into the Java `nativeBuffer` (direct `ByteBuffer`). |
| `CAStreamInputStream.cpp` | Creates an `AudioFileStreamID` with callbacks that pull data from a Java `InputStream`. |
| `CACodecInputStream.cpp` | Sets up `AudioConverterRef` for PCM conversion. `CACodecInputStream_ComplexInputDataProc` is the Core Audio callback that feeds compressed data from the source Java stream. |

## JNI Headers

Generated by `javac -h` during the `compile` phase of `casampledsp-java` into `../casampledsp-java/target/native/include/`. Do not edit headers by hand.

## Editing C++ Code

Changes to any `.cpp`/`.h` file here affect **both architectures** (x86_64 and aarch64). Always verify with a full `mvn install` before considering a change complete.
