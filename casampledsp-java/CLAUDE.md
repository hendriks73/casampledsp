# casampledsp-java

Authoritative Java SPI implementation module. Contains all `com.tagtraum.casampledsp` Java sources. Compiled standalone; sources are also **copied** into `casampledsp-complete` at build time by the Maven resources plugin.

## Build

```bash
# Java-only (no native):
mvn install -pl casampledsp-java

# After editing Java: fix formatting before the build checks it:
mvn spotless:apply -pl casampledsp-java
```

Java compiler target is `<release>8</release>`, set in the root `pom.xml`.

## Key Classes

| Class | Role |
|---|---|
| `CAAudioFileReader` | `AudioFileReader` SPI. Opens URLs/files/streams via Core Audio. |
| `CAFormatConversionProvider` | `FormatConversionProvider` SPI. Converts compressed formats to `PCM_SIGNED`. |
| `CAURLInputStream` | Native-backed stream from a URL or file path. Backed by `AudioFileID`. |
| `CAStreamInputStream` | Native-backed stream from a Java `InputStream`. Backed by `AudioFileStreamID`. |
| `CACodecInputStream` | Core Audio `AudioConverterRef`-backed format converter (e.g., MP3 → PCM). |
| `CAAudioFormat` | Audio format metadata; defines `CAEncoding`. |
| `CAAudioFileFormat` | File-level format metadata (duration, byte length, type). |
| `CAAudioInputStream` | Wraps `CANativePeerInputStream`; implements seeking via `seek(long, TimeUnit)`. |
| `CANativeLibraryLoader` | Extracts architecture-appropriate embedded `.dylib` to `java.io.tmpdir` and loads it. |
| `CANativePeerInputStream` | Abstract base holding a `long nativePeerPointer` to the C++ struct on the heap. |

## JNI Interface

Native methods are declared on `CANativePeerInputStream` subclasses. JNI headers are generated by `javac -h` into `target/native/include/` during the `compile` phase and consumed by the native modules.
